# 历史源码包归档建议

## 1. 当前已有归档包

- `2.0源码.zip`
- `3.0.zip`
- `4.0源码.zip`
- `5.0.zip`
- `6.0.zip`
- `7统计优化和改写.zip`
- `8.0备份和合并.zip`

## 2. 推荐做法

### 当前维护方式
- 只把一个当前稳定版本解压到 `app/`
- 其他版本只在文档中记录，不直接混入主线

### 归档方式
可选：
1. 保存在本地离线归档目录
2. 通过 GitHub Release 附件保留
3. 存到私有网盘 / 校内存储

## 3. 不建议做法

- 不建议把所有 zip 包都长期提交到仓库根目录
- 不建议把多个历史版本全部解压后放到 `app/`
- 不建议让归档包和当前主线共同参与日常开发

## 4. 文档留痕原则

即使 zip 不进仓库，也应在：
- `CHANGELOG.md`
- `VERSION_POLICY.md`
- `ARCHIVE_PLAN.md`

中明确写出归档名称和阶段定位。
