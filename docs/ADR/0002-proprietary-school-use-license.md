# ADR 0002: Proprietary School-Use License

## Status

Accepted.

## Context

The project is visible for reference and maintenance, but the rights holder does not grant open redistribution, commercial use, hosted deployment, or derivative publication.

## Decision

Use proprietary licensing with a separate school-use document for authorized internal campus use.

## Consequences

- `app/package.json` is `UNLICENSED` and private.
- License, school-use, EULA, privacy, and third-party notices are required.
- Public visibility does not imply open-source permission.
