# 项目概览

## 项目名称
校园植物分区管理系统

## 项目定位
用于校园植物调查、点位记录、物候信息录入、图片管理、查询统计与项目级数据维护的本地桌面系统。

## 核心设计原则

1. **地图主链路优先稳定**
2. **数据字段尽量统一**
3. **附加功能采用独立窗口或附加层实现**
4. **项目目录可迁移、可备份、可合并**
5. **界面可逐步优化，但不轻易破坏核心链路**

## 当前适合 GitHub 管理的内容

- Electron 源码
- 界面资源
- 文档
- 示例数据
- 打包说明

## 当前不适合直接公开提交的内容

- 真实项目数据
- 真实调查图片
